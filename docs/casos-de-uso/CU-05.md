# CU-05 Cobrar pedido

- **Versión:** v1.0
- **Actores:** Cajero (primario), Cliente
- **Historias de usuario:** HU-11, HU-13
- **Pruebas:** PR-15, PR-16, PR-19

## Precondiciones
El pedido está listo para ser cobrado.

## Flujo principal
1. El Cajero informa el monto total.
2. El Cliente elige el medio de pago: efectivo, Yape/Plin o tarjeta.
3. Efectivo: el Cajero recibe el dinero y calcula el vuelto. Yape/Plin: muestra el QR y verifica la operación. Tarjeta: procesa el pago en el POS.
4. El sistema confirma el pago.
5. Se emite el comprobante (include CU-06).
6. El Cajero registra el pago en el libro de caja del día.

## Flujos alternos
- 4a. Si el pago no se confirma, el Cajero informa de nuevo el monto y el Cliente elige otro medio.

## Postcondiciones
Pago confirmado, comprobante emitido y pago registrado en el libro de caja.

«include» CU-06.
