# CU-07 Gestionar inventario de insumos

- **Versión:** v1.0
- **Actores:** Administrador
- **Historias de usuario:** HU-06
- **Pruebas:** PR-10

## Precondiciones
El Cocinero notificó un faltante de insumos.

## Flujo principal
1. El Administrador revisa el faltante.
2. Repone los insumos o autoriza un reemplazo del producto.
3. El sistema actualiza el inventario y la preparación continúa.

## Flujos alternos
Ninguno.

## Postcondiciones
Faltante resuelto y inventario actualizado.

## Relaciones
Usado desde CU-03.
