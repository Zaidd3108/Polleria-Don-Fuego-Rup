# CU-09 Registrar datos de delivery

- **Versión:** v1.1 (CR-001)
- **Actores:** Cajero
- **Historias de usuario:** HU-03, HU-15
- **Pruebas:** PR-05, PR-06, PR-21, PR-22

## Precondiciones
La modalidad del pedido es delivery (extiende CU-01).

## Flujo principal
1. El Cajero registra nombre, teléfono y dirección del Cliente (solo para la entrega, Ley N.° 29733).
2. El sistema verifica que la dirección esté dentro de la zona de cobertura.
3. El sistema asigna el costo de envío de la zona (CR-001) y lo suma al total.

## Flujos alternos
- 2a. Si la dirección está fuera de cobertura, el pedido de delivery se cancela.
- *. En pedidos de consumo en el local no se ejecuta este caso de uso ni se cobra envío.

## Postcondiciones
Datos de entrega registrados con costo de envío, o pedido cancelado.

## Relaciones
«extend» CU-01.
