# CU-02 Validar stock disponible

- **Versión:** v1.0
- **Actores:** Cajero
- **Historias de usuario:** HU-02
- **Pruebas:** PR-03, PR-04

## Precondiciones
Hay productos y cantidades registrados en el pedido (invocado desde CU-01).

## Flujo principal
1. El sistema verifica el stock de cada producto solicitado.
2. Si todos tienen stock, devuelve el control a CU-01.

## Flujos alternos
- 1a. Si un producto no tiene stock, el Cajero informa el faltante y ofrece una alternativa.
- 1b. Si el Cliente acepta, el Cajero vuelve a registrar los productos y se repite la validación.
- 1c. Si el Cliente rechaza la modificación, el pedido queda cancelado.

## Postcondiciones
Stock validado para todos los productos, o pedido cancelado.

## Relaciones
Incluido por CU-01.
