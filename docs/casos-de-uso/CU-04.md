# CU-04 Despachar delivery

- **Versión:** v1.0
- **Actores:** Repartidor
- **Historias de usuario:** HU-09, HU-10
- **Pruebas:** PR-13, PR-14

## Precondiciones
El pedido es de modalidad delivery y está preparado (CU-03).

## Flujo principal
1. El Repartidor recoge el pedido.
2. Lo traslada a la dirección registrada.
3. El Cliente recibe el pedido.
4. El Repartidor entrega y confirma la recepción; el pedido queda entregado.

## Flujos alternos
- 3a. Si el Cliente no es ubicado, el Repartidor reintenta el contacto.
- 3b. Si no hay respuesta, retorna el pedido al local; queda como no entregado y se reporta al Administrador.

## Postcondiciones
Pedido entregado o no entregado con reporte al Administrador.

## Relaciones
«include» CU-03 (según la descripción de procesos).
