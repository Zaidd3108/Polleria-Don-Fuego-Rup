# CU-06 Emitir comprobante electrónico

- **Versión:** v1.1 (CR-001)
- **Actores:** Cajero
- **Historias de usuario:** HU-12
- **Pruebas:** PR-17, PR-18, PR-23

## Precondiciones
El pago está confirmado (invocado desde CU-05).

## Flujo principal
1. El Cliente indica si solicita boleta o factura.
2. Si es factura, el Cajero registra RUC y razón social y el sistema valida el RUC.
3. El sistema emite el comprobante electrónico (en delivery detalla el costo de envío, CR-001).
4. El Cajero lo entrega impreso o por WhatsApp.

## Flujos alternos
- 2a. Si el RUC no es válido, se solicita la corrección de los datos.

## Postcondiciones
Comprobante electrónico emitido y entregado.

## Relaciones
Incluido por CU-05.
