# CU-01 Registrar pedido

- **Versión:** v1.1 (CR-001)
- **Actores:** Cajero (primario), Cliente
- **Historias de usuario:** HU-01, HU-04, HU-05, HU-15
- **Pruebas:** PR-01, PR-02, PR-07, PR-08, PR-09, PR-23

## Precondiciones
El Cajero tiene sesión iniciada y el Cliente solicita un pedido (local, teléfono o WhatsApp).

## Flujo principal
1. El Cliente solicita un pedido.
2. El Cajero registra productos, cantidades y el canal del pedido.
3. El sistema valida el stock de cada producto (include CU-02).
4. El Cajero consulta la modalidad: consumo en el local o delivery.
5. Si es delivery, se registran los datos de entrega (extend CU-09).
6. El sistema calcula el total (en delivery incluye el costo de envío, CR-001) y el Cajero lo comunica al Cliente.
7. El Cliente confirma el pedido.
8. El sistema genera un ticket con número único y envía la orden a cocina.

## Flujos alternos
- 6a. Si el Cliente no confirma el pedido, el pedido queda cancelado.

## Postcondiciones
Pedido confirmado, con ticket único y orden enviada a cocina; o pedido cancelado.

## Relaciones
«include» CU-02. Extendido por CU-09.
